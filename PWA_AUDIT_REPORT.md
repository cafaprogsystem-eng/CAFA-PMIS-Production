## 6. Desktop View Mode ✅

A **Desktop View toggle** button (monitor icon) appears in the header on mobile/tablet screens. Tapping it switches the viewport between:

- **Mobile View** (default): `width=device-width` — fully responsive layout
- **Desktop View**: `width=1280` — renders the full desktop layout scaled to fit the phone screen, useful for accessing complex data tables or dense views

Preference is saved in `localStorage` so it persists across sessions.

## Certification boundary and remaining recommendations

The historical checkmarks below describe implemented source/assets, not a
current deployed-browser result. A Vite development worker, local preview, or
static source inspection cannot prove production-build PWA install, authenticated
offline reload/reconnect, account isolation, or device/browser behaviour. Those
checks remain in the isolated AWS staging certification register.

1. **Full-size iOS splash images** — proper 2x/3x PNG splash screens matching exact device resolutions would improve the iOS launch animation. Currently uses the 512px icon as fallback.
2. **Push notifications** — can be added via Web Push API for critical risk/approval alerts.
3. **Background sync** — replace the online-event trigger with the Background Sync API for more reliable sync after spotty connections.
4. **Arabic (RTL) full-app i18n certification** — source-level localization
   safeguards exist; exercise the routed Arabic UI in isolated staging before
   treating the full-app experience as certified.
